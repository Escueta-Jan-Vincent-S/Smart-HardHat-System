Welcome to SMSYS

Smart Monitoring for Safer Construction Sites

SMSYS is a safety monitoring system for construction sites. It uses a Smart Hardhat to monitor workers in real time so supervisors can respond to hazards early.

The dashboard tracks PPE compliance, worker drowsiness, device connectivity, and worker location by zone.

Features

Delivering Safety Through Smart Monitoring

PPE Detection

Checks hardhats, vests, gloves, and boots, and reports violations.

Drowsiness Alerts

Detects signs of fatigue so supervisors can act before an incident.

Zone Localization

Shows the floor and zone where each worker is located.
